System requirements

  • macOS: Mac with Apple silicon. Desktop app.
  • Linux: x64, as a .deb package or an AppImage. The desktop app needs WebKitGTK.
  • Windows: x64, command-line tool only for now. The desktop app for Windows is coming soon.
  • A model provider key from OpenAI, Azure OpenAI or Anthropic.
  • A repository on your machine to point CoreStory at.

Install and add your model key

Desktop app

  1. Download the app for your platform from the download buttons above and open it.
  2. Agree to the terms of use and privacy policy. A checkbox lets you choose whether to send anonymous usage data.
  3. Choose your model provider (OpenAI, Azure OpenAI or Anthropic) and paste your key. CoreStory saves it to ~/.config/corestory/config.toml, readable only by you.
  4. Pick a Git repository folder. CoreStory indexes it locally and opens the map.

You only see the terms and model steps the first time. After that, the app opens straight to the folder picker.

Command-line tool

Download the command-line tool for your platform from the latest release, put corestory on your PATH, then from your repository run:

corestory --version
cd your-repo
corestory init
corestory ingest
corestory refine

This creates .corestory/store.db inside the repository and adds it to .gitignore.

Connect your coding agent

Your agent talks to CoreStory through the corestory command-line tool, which serves the repository's map over MCP. Install the command-line tool first (see above) and make sure corestory is on your PATH.

Claude Code

Install the local CoreStory plugin. It needs no account and makes no network calls.

claude plugin marketplace add corestoryai/agent-skills
claude plugin install corestory-local@corestory

The plugin runs corestory mcp --path <workspace> --no-watch for the folder you have open, and adds the CoreStory skills.

GitHub Copilot, VS Code and Cursor

Add a .mcp.json file at the root of your repository:

{
  "mcpServers": {
    "corestory": {
      "type": "stdio",
      "command": "corestory",
      "args": ["mcp", "--path", "/absolute/path/to/repo", "--no-watch"]
    }
  }
}

Codex

Add the server to your Codex configuration (~/.codex/config.toml):

[mcp_servers.corestory]
command = "corestory"
args = ["mcp", "--path", "/absolute/path/to/repo", "--no-watch"]

Add the CoreStory skills with the GitHub CLI:

gh skill install corestoryai/agent-skills --all --agent codex --scope user

Gemini CLI

gemini extensions install https://github.com/corestoryai/agent-skills
