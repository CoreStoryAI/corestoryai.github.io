BUILD FROM SOURCE

Public source, gated image.

No public image has been released yet. Clone the appliance beside an authorized Plot checkout and build the preview locally.

BUILD

Create the image

docker build \
  --build-context plot=../plot \
  -t plot-container-poc:local \
  .

RUN

Keep it local

docker volume create plot-container-data
docker run --rm \
  -p 127.0.0.1:8080:8080 \
  -v /path/to/repo:/workspace:ro \
  -v plot-container-data:/data \
  plot-container-poc:local

USE

Explorer and MCP arrive together.

Explorer: http://127.0.0.1:8080/app

MCP: http://127.0.0.1:8080/mcp

Health: http://127.0.0.1:8080/ping

Configuration may be mounted at /config/config.toml. CS_ environment variables retain normal precedence.

RELEASE BOUNDARY

Do not expose this preview.

The appliance has no authentication and is intended for a single local corpus. Bind it to loopback, use a separate state volume for each repository, and do not expose it to a LAN or the internet.

The reserved canonical image location is ghcr.io/corestory-frontier/plot-container. Publication remains blocked on redistribution approval, multi-architecture verification, SBOM, provenance, scanning, signing, and exact-digest runtime tests.
